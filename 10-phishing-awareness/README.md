# Phishing Simulation and Credential-Safety Awareness

## Objective
Document observations from a phishing-tool exercise and explain why credential-harvesting simulations must be tightly controlled.

## Evidence
![Phishing tool lab output](evidence/socialphish-lab.png)

## Observation
The screenshot shows a SocialPhish terminal interface, a local URL, and output indicating that test input was saved. It also visibly includes example account and password values.

## Safety and publication note
**Do not publish this original screenshot as-is.** It displays a password-like value and a credential-capture workflow. Replace it with a redacted version that hides all usernames, passwords, saved credential paths, and any live or reachable phishing URL. Keep the exercise confined to a local, authorised simulation using dummy data.

## Analysis
The screenshot demonstrates the risks of credential-harvesting tooling, but it should not be used to advertise a working phishing page or credential collection capability.

## Recommendations
Use approved awareness simulations, dummy credentials, phishing-resistant MFA where possible, and clear reporting procedures.
