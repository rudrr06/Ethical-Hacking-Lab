# Open-Source Intelligence (OSINT) Investigation

## Objective
Practice a repeatable method for collecting and cross-checking publicly available information about an organisation or a lab-approved subject without accessing private accounts or bypassing controls.

## Concepts
OSINT is the collection and analysis of information from lawful, publicly accessible sources. Individual observations can be inaccurate or outdated, so important claims should be corroborated and confidence should be recorded.

## Tools and scope
- Reference directory: [OSINT Framework](https://osintframework.com/).
- Possible source categories: official websites, public WHOIS/RDAP records, public DNS records, reputable IP-registration information, and public company pages.
- Use an organisation you own, a purpose-built training target, or a subject for whom you have explicit permission. Do not search for or publish private personal information or leaked credentials.

## Step-by-step procedure
1. Write down the approved subject and the exact scope before searching.
2. Open the OSINT Framework website and select a relevant category such as domain, IP address, or public website information.
3. Start with the subject's official website and note the exact source URL and date checked.
4. For an authorised domain, check public registration information and DNS records using reputable public lookup services.
5. Cross-check each important observation against a second independent source where possible.
6. Keep facts separate from inferences. For each item, record the source, date, confidence (high/medium/low), and limitations.
7. Exclude private account details, passwords, breach dumps, and information unrelated to the approved purpose.
8. Summarise only the minimum information needed to answer the assessment question.

## Analysis
Public availability does not automatically make information appropriate to redistribute. OSINT results can be stale, misattributed, or misleading when interpreted without context.

## Defensive recommendations
Reduce unnecessary public metadata, review DNS and domain records, remove accidental disclosures, and establish a process for handling reported exposure.
