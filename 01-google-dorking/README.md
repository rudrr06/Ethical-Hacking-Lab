# Google Dorking for Public Document Discovery

## Objective
Explore how the `site:` and `filetype:` search operators identify publicly indexed PDF documents.

## Method
A Google search was performed using `site:skills-factory.com filetype:pdf`.

## Evidence
![Google search results](evidence/google-dorking.png)

## Observation
The results page displayed multiple PDF documents indexed under the specified domain, including course brochures.

## Analysis and limitations
This demonstrates search-operator use and public indexing. It does **not** establish that any document is confidential or that a vulnerability exists. The contents and intended audience of a document must be reviewed before making such a claim.

## Responsible handling
Only review documents intended to be public. Do not republish copyrighted files or personal/confidential information.
