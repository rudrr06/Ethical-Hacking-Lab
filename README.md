## Important notes
- Screenshots are mapped to the project they actually support.
- Some screenshots contain sensitive-looking values or infrastructure details. The phishing and Wireshark images must be redacted and reviewed before public upload.
- Scanner alerts and service banners are observations, not automatic proof of exploitability.
- Testing should be limited to systems owned by you or explicitly authorised.
- No credentials, hashes, payload binaries, or private data should be published.
